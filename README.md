# Iris Flower Classifier 🌸

## 📌 Project Overview
This is a foundational Machine Learning project. The goal is to build a model that can classify Iris flowers into three different species (Setosa, Versicolor, Virginica) based on their sepal and petal measurements.

## 🛠️ Technologies Used
- **Language:** Python
- **Libraries:** Scikit-Learn

## 🧠 How it Works
The script (`iris_model.py`) does the following:
1.  **Loads** the famous Iris dataset, which is built directly into the Scikit-Learn library.
2.  **Splits** the data (80% for training, 20% for testing).
3.  **Trains** a K-Nearest Neighbors (KNN) classifier model.
4.  **Evaluates** the model's accuracy.
